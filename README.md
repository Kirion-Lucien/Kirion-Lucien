## ◇ FRAMES BEFORE DECORATION

The visual layer matters — but it comes **after the structure makes sense**.

Before polishing a screen, I care about:

`what belongs together` · `what deserves attention` · `what changed` · `what can fail` · `what happens next`

> **Make the next action obvious without making the interface loud.**
